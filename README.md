# AR Food Visualizer

AR-додаток на Unity 6 (6000.6.0f1) + AR Foundation 6.6 під Android.
Варіант 10: віртуальні моделі їжі.

## Лабораторна робота №2
- Детекція горизонтальних площин (`ARPlaneManager`)
- Розміщення моделі піци по тапу та переміщення повторним тапом (`ARRaycastManager`, `TrackableType.PlaneWithinPolygon`)
- Вивід стану AR-сесії (`ARSession.state`, `ARSession.stateChanged`)
- Кнопка показу/приховування площин

Сцена: `Assets/Scenes/SampleScene.unity`
Скрипти: `Assets/Scripts/`
